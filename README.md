# E-Commerce
Project Objective
To perform in depth analysis on the e-commerce dataset in SQL, and further use python for any required visualizations.

Dataset used
Dataset: e-commerce dataset
Questions
Basic Queries

Find the top 10 most frequently purchased products.
List the number of sellers operating in each state.
Find the number of products listed in each category.
Find the total sales per category.
Calculate the percentage of orders that were paid in installments.
Intermediate Queries

Calculate the average delivery time (difference between order purchase and delivery) by state.
Identify the top 5 product categories with the highest return rate.
Find the relationship between installment payments and order value (average order value when paid in installments vs. full payment). Find correlation in Python.
Find the average number of products per order, grouped by customer state.
Calculate the percentage of total revenue contributed by each product category.
Advance Queries

Distribute the orders across spend tiers (Very Low, Low, Medium, High, Very High).
Find top 5 sellers' market share in each category.
Calculate the month-on-month growth rate of total sales.
Calculate the cumulative sales per month for each year.
Statewise Delivery performance (Eary, On Time, Late).
Process
Post downloading the dataset archieve(zip file), it is extracted in a seperate folder.
Used jupyter notebook to push the tables to SQL server(MySQL localhost used in this project).
Fired all the queries in SQL database using appropriate functions, joins, filters, CTEs, windows function, etc.
Running the same queries in jupyter notebook using mysql connector library and viewing the output as a dataframe.
Further created any relevant plots like bar charts, line charts, etc. using matplotlib and seaborn library.
Conclusion
SQL is used in tandem with python to meet the project objective and perform the required analysis on the e-commerce dataset.
